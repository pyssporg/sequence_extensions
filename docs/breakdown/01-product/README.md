# 01-product — Product

What users need — the use-case catalog and capability leaves for the engine and the GUI, stated in user-observable terms with acceptance and evidence.

## Ask

"What do users need?" — the engine use cases (`use-cases/`, `CP-016`..`CP-030`), the GUI use cases (`use-cases/`, `CP-036`..`CP-044`), the planning journeys (`planning/`, `CP-031`..`CP-035`), and the GUI requirements (`gui-application/`, `REQ-001`..`REQ-004`).

## When to Read

- Before promising or changing a capability.
- When an integrator asks what the engine or the GUI must do for its users.

## Boundary

- Holds the needs only.
- Not the delivered surface or the design: `02-architecture/`.
- Not how the code is written: `03-implementation/`.
- Scope and vision: `00-intent/` (INFO-001).
